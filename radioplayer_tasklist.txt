Batch 8 - Visual fixes
----------------------
[ ] B1  The main app window only has rounded corners at the top, not the bottom.
        Root cause: WPF ClipToBounds clips to the rectangular layout bound, not the visual
        rounded shape. Fix: set UIElement.Clip to a RectangleGeometry(r=13) in code-behind
        and update it on SizeChanged / StateChanged (clear clip when maximized).
[ ] B2  The left edge of the window has a 1-2px visual artifact (background image appears
        to stick out). Likely a DPI sub-pixel rendering issue from the 1px shell border.
        Fix: add UseLayoutRounding=True + SnapsToDevicePixels=True on the shell Border.
[ ] B3  The Add/Edit/Delete station buttons sit too close to the bottom-left corner.
        Fix: increase bottom margin on the left panel DockPanel (14,16,14,8 -> 14,16,14,14).
