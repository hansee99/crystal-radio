Build notes
Idle state is unchanged (the screenshot's Describe a vibe… / Start row). On SessionActive, collapse that row and swap the card's vibe TextBlock for a 2-line-min TextBox (AcceptsReturn=False, TextWrapping=Wrap, auto-height, cap ~4 lines then scroll). Enter = Update, Esc = Cancel, and focus lands in the box with text selected so retyping is one gesture. Card grows downward; the Mix list absorbs it.
1b
Prompt gets its own row
Keep the live prompt row, but stop making the field and the button share a line. Field spans the full panel and wraps; the button drops beneath it, right-aligned, and only appears once the text differs from the running vibe.
