b06 · Session block
Prompt + inline Start replace two full-width pills. Once running, the block becomes the session record: vibe, live dot, counts. End session is a ghost button and only exists while there's something to end.
b08 · Content first
Mix leads, Sources second — matching Stations-then-Search and Songs-then-Curate. Tabs get a 32px band and sit at the same baseline as the other two modes.
b10 · Header action
The 32×32 action lives in the list header it acts on, not stranded at the panel foot — save the whole mix on Mix, add a station to the pool on Sources.
b11 · DJ intro promoted
15px italic Secondary in its own bordered block on a solid surface — the mode's signature line, no longer 12.5px muted text floating on artwork.
Also visible here
The status line has moved inside the panel it describes, so the "warming up" checklist now occupies the space that used to say "Not harvesting yet" (b02/a04). Now Playing shows the bridging station live during warm-up instead of "Not playing". Steady state uses the pulsing dot, not a spinner. Source rows read "Listening… / 6 songs" rather than "0 song titles seen", and every icon button is 32×32.
