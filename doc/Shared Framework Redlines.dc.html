CHANGE LOG
1Unified sub-navigation
Library gains the same three-tab pattern Radio uses. Stations / Search / History is mirrored by Playlists / Curate / Songs — one mental model for both modes.
2Right panel earns its space
Radio no longer shows a bare “Not playing.” When a station is selected it surfaces the on-air track and a Recently on this station list, so the panel is useful even before playback.
3Labeled actions, no mystery glyphs
“About this track” and “Save to Library” become labeled pills. In lists, the save control shows its state: download → check when already saved. Every icon-only control gets a tooltip.
4Curate reads as curate
The Library “+” box becomes the Curate tab. The natural-language query and its resulting playlist are shown as a titled context card, so query ≠ queue confusion disappears.
5Descriptions breathe
List descriptions clamp to a consistent two lines instead of a hard single-line cut, so “non-commerci…” becomes readable context.
6One right-panel anatomy
Both modes use the same slots and positions. The only difference: the progress region is a scrubber in Library and a LIVE badge in Radio. Transport + volume are identical.
7About: consistent icons
The header and Regenerate control currently use a generic “+” glyph. Both switch to the sparkle — the same mark used to trigger About everywhere else, so the feature reads as one thing.
8About: refined scroll
Replace the chunky native scrollbar with a slim custom thumb plus a bottom fade, so the reading text dissolves at the fold instead of being hard-clipped mid-line.
SHARED ANATOMY
Left panel — identical in both modes
1 · Mode toggle — Radio / Library
2 · Sub-nav — 3 tabs
3 · Scrollable list of rows
stations · songs · history · results
4 · Footer toolbar — add / count
Right panel — same slots, one swappable region
A · Context eyebrow (NOW PLAYING)
B · Title — track or station
C · Secondary — artist / genre
D · Source chip — station / playlist
E · Actions — About · Save
F · Progress region ⇄
Library: scrubber · Radio: LIVE + recent
G · Transport — prev / play / next / stop
H · Volume
“About this track” opens as a replace-view over slots A–F (back button returns) — the same interaction already spec'd, now available in both modes wherever a track is known.
